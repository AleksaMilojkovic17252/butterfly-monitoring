{% load i18n l10n %} {% comment %} EditableMapWidget (T098). A copy of Django's gis/openlayers.html + openlayers-osm.html with a "Delete selected" button and a "?" help popup added. Django's MapWidget looks for .clear_features right after the map div, so keep that order. Subclass templates can override the delete_selected_label and help blocks (e.g. lines instead of polygons, T022). The options are repeated as data- attributes because a form added by the admin's "Add another" does not run the script below: EditableMapWidget.initIn() builds its widget from them. The empty form that Django clones for that (its id holds "__prefix__") must stay a plain
, so it gets no script. {% endcomment %}
