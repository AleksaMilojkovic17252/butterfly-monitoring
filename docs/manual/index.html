Butterfly Monitoring User manuals

User manuals

Butterfly Monitoring is a system for standardised butterfly transect surveys, also called Pollard walks. Researchers record visits, GPS routes, butterflies, plants and habitat on an Android phone, with or without a connection. Admins prepare the projects, check the records and export the data.

Researcher manual

For people who walk transects with the phone app.

Getting started, walking a visit step by step, recording butterflies, plants and habitat, the map, sync, and what every message means.

Admin manual

For people who run a project with the web admin.

Users, projects and protocols, transects, species lists, reviewing and locking visits, validation, sync conflicts, exports, QGIS, and running the server.

Which one do I need?

  • If you only use the app, read the researcher manual.
  • If you log in to the website at /admin/, read the admin manual. It helps to skim the researcher manual too, so you know what your researchers see.

About these manuals

They describe the system as it works in November 2026. It is still being developed, so purple Coming later boxes mark planned features and amber For now boxes mark things that will get simpler. Each manual is one long page: use your browser's search (Ctrl+F) to find a word, or print the page to get a PDF.
